# CampusConnect — Professional Front-End Web Technology Project

## Project
Student Event Management / Campus Event Discovery Portal

## Front-End Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts (DM Sans + Manrope)

## Pages
- `index.html` — modern landing page
- `events.html` — searchable/filterable event directory
- `register.html` — responsive registration form with validation
- `about.html` — project overview and future scope

## Features
- Responsive mobile navigation
- Modern professional UI
- Hero section and statistics
- Event cards and event directory
- Live event search
- Category filtering
- Registration form with HTML validation
- Event pre-selection through URL parameters
- Registration success state
- Responsive design for desktop, tablet and mobile
- No backend required

## How to Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet is only needed if you want the Google Fonts to load; the project otherwise works as a static front-end.
